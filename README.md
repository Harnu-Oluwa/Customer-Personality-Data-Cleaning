# Customer-Personality-Data-Cleaning

Project Overview
This project demonstrates the data cleaning process performed on Customer Personlity Analysis dataset.

Data Cleaning Tasks
- Renamed column headers
- Format date column
- Checked for blank cells
- Filled blank income values using median
- Checked for duplicate records
- Verified data types
- Reviewed the dataset for inconsistencies and outliers.

  Tools used
  - Microsoft Excel
  - ChatGPT
  - Google AI
